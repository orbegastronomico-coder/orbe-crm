# OrBe CRM 🚀

Corporate CRM designed for operational control, sales pipeline management, and AI-driven insights. Built with a focus on speed, real-time collaboration, and a polished user interface.

## ✨ Features

- **📊 Dashboard**: Real-time overview of KPIs, revenue metrics, and growth trends.
- **🛣️ Pipeline**: Kanban-style management for leads and clients with detailed interaction history.
- **🗃️ Client Database**: Searchable database of contacts and companies with advanced filtering.
- **🤖 AI Integration**: Integrated Google Gemini API for operational tips and data extraction.
- **⚡ Real-time Persistence**: Supabase backend for instant synchronization across sessions.
- **📱 Responsive Design**: Fully optimized for mobile and desktop workflows.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Motion](https://motion.dev/)
- **Backend**: [Supabase](https://supabase.com/)
- **AI**: [Google Gemini API](https://ai.google.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- A Supabase project
- A Gemini API Key

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/orbe-crm.git
   cd orbe-crm
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure Environment Variables:
   Create a `.env` file in the root directory and copy the variables from `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Then fill in your actual credentials.

4. Start Development Server:
   ```bash
   npm run dev
   ```

## 📁 Project Structure

- `src/App.tsx`: Main application logic and routing.
- `src/index.css`: Global styles and Tailwind configuration.
- `src/lib/`: Utility functions and service initializations.
- `metadata.json`: Application metadata and permissions.
